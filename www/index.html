System WebKit, not Chromium

No Puppeteer or bundled browser in npm. og-render is a small native CLI that snapshots HTML through the WebKit already on your Mac.

Real typography

Google Fonts and variable fonts load at render time. Full CSS metrics — no font subsetting, no npm font packages.

Declarative API

Configure OG images with simple JSON. Pick a template, set your title, export a PNG.

Site-wide Auditing

Audit your entire site's OG tags via sitemap. Catch issues before you ship.

Local Viewer

Preview OG images locally with live renders before deploying.

Batch Generation

Generate multiple images at once. Perfect for blogs and documentation.
